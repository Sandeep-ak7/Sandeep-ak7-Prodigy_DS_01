# Task-01: Data Visualization using Bar Chart/Histogram

## 📌 Objective

The objective of this task is to create a **bar chart** or **histogram** to visualize the distribution of a **categorical** or **continuous variable**. This visualization helps in understanding the data distribution, spotting patterns, and identifying any potential outliers.

## 📊 Task Description

We use a dataset containing demographic information to plot the distribution of a selected variable:

- **Bar Chart**: Used for **categorical variables** like gender, occupation, etc.
- **Histogram**: Used for **continuous variables** like age, income, etc.

## 🛠️ Tools and Libraries

The following Python libraries were used:

- `pandas` – for data manipulation
- `matplotlib` – for plotting charts
- `seaborn` (optional) – for enhanced visual styling

## 📁 Dataset

A sample dataset is either:

- Loaded from a `.csv` file
- Created manually within the script

Variables used may include:
- `Age` (continuous)
- `Gender` (categorical)

## 📈 Output

The script generates:
- A **bar chart** showing the count of each gender in the population
  _or_
- A **histogram** showing the distribution of ages
